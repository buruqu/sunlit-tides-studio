# 调色板与编辑面板优化

联合版本：Codex 2.1.1 / DSH 0.3.1。沿用 2.1.0 的面板拖动、素材工程和主题设置。

- 调色板按阅读、背景、角色、动效等功能分组，删除重复说明，固定标题和底部操作。
- 编辑器跟随亮暗外观，素材、布局、字体、特效分别展示相关内容。
- 撤销、重做保留在内容顶部；恢复默认、恢复上次保存、导入和导出归入「工程」。
- 画布选择与预设添加同步切换分类和导入用途。
- 统一字号、间距和控件层级，改善窄窗排版与独立面板按钮对比。

主题壁纸、人物动画、落叶与泡泡、文字渐变和用户工程保持兼容。DSH 不包含 GPT 启动动画。

## 安装范围

使用包内原有安装入口。Codex 更新辅助程序及受管主题文件，主程序无需重启。DSH 更新受管插件，须在全局运行任务结束后正常退出，再安装和重开。安装前创建新的恢复点，保留原设置与素材工程。

建议本批维护窗口 10 分钟，预留后 4 分钟恢复；耗时为估计。Codex 安装失败使用安装器恢复，外观验收失败可先恢复官方外观；DSH 使用安装器生成的本次备份执行恢复。恢复主题代码不回退用户工程。

## 验证范围

已在两端合成宿主的真实 Edge 中检查亮暗、桌面和窄窗、各设置分类，以及素材导入、编辑、撤销、取消、保存和刷新。独立面板颜色使用真实面板控制器导出的内容验证。
